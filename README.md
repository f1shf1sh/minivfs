## 总体架构
```
┌──────────────────────────────┐
│         文件系统层（FS）        │
│  ├── inode / directory        │
│  ├── metadata / journaling    │
│  └── 提供文件接口给用户态        │
└──────────────▲───────────────┘
               │
┌──────────────┴───────────────┐
│        Block Manager 层      │
│  ├── block 分配与回收（bitmap）│
│  ├── 逻辑块号 ↔ 物理块号映射    │
│  ├── 块缓存管理接口            │
│  └── 依赖 cache_mgr           │
└──────────────▲───────────────┘
               │
┌──────────────┴───────────────┐
│          Cache 层            │
│  ├── LRU 块缓存               │
│  ├── 脏页写回机制              │
│  ├── 异步同步（future）        │
│  └── 调用 vdev 层             │
└──────────────▲───────────────┘
               │
┌──────────────┴───────────────┐
│         虚拟设备层（VDev）     │
│  ├── 统一块设备接口 vdev_ops  │
│  ├── 多设备注册表 vdev_table  │
│  ├── 可挂载/卸载              │
│  └── 设备抽象：disk / ramdisk │
└──────────────▲───────────────┘
               │
┌──────────────┴───────────────┐
│           Disk 层             │
│  ├── 文件模拟磁盘 (file fd)   │
│  ├── block 读写 / sync        │
│  └── 注册为 VDev("disk")      │
└──────────────────────────────┘
```
## 格式化结构

```
+-------------------+---------------+
|   Boot Block      |     Block 0   |
+-------------------+---------------+
|   Superblock      |     Block 1   |
+-------------------+---------------+
|     Log           |  Blocks 2-31  |
+-------------------+---------------+
|   Inode Blocks    | Blocks 32-47  |
+-------------------+---------------+
|   Bitmap Blocks   | Blocks 48-49  |
+-------------------+---------------+
|    Data Blocks    | Blocks 50-... |
+-------------------+---------------+
```
